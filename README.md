# Lab 4 Reflection

Encapsulation helped break the drawing into smaller functions for things like the pumpkin, eyes, mouth, and stars instead of putting all of the code in one place. This made it easier to work on and fix one part of the drawing without having to change everything else.

Generalization made the functions reusable by letting us give them different values for things like position and size. For example, the same pumpkin and eye functions could be used to make multiple pumpkins in different locations and sizes. Breaking the scene into smaller reusable functions made the final drawing much easier to put together.
